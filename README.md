# NHL Totals Lab Data Feed

Public data-only companion repository for NHL Totals Lab.

It mirrors the MoneyPuck team/goalie datasets used by the Android WebView and also carries a compact official NHL fallback: current rosters, a short schedule window with canonical NHL game IDs, and available game-center boxscore context. This lets the app repair IDs and goalie rosters even when direct NHL Web API access is blocked by Android WebView/CORS.

Updated automatically every hour. Public stats only; no Data Vault, bets, keys or private app data are stored here.
